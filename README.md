## 💡 La idea

Cuando un visitante llega al sitio de una agencia de desarrollo, normalmente llena un formulario genérico o espera a que alguien lo contacte para hacerle las mismas preguntas de siempre: tipo de proyecto, presupuesto, plazo, contacto.

Este asistente reemplaza ese formulario por una conversación natural — y mientras el visitante responde, va armando en tiempo real un **brief estructurado** (panel `brief.json`) que el equipo de ventas puede recibir listo para actuar, sin tener que repetir la primera llamada exploratoria.

## ⚙️ Cómo funciona

- El visitante conversa con el asistente sobre su proyecto.
- Cada respuesta se procesa para extraer: tipo de proyecto, alcance, presupuesto, plazo y datos de contacto.
- El panel lateral se actualiza en vivo, con barra de progreso y nivel de urgencia inferido.
- Al completarse el brief, aparece un botón para enviarlo directo al equipo por WhatsApp, ya redactado.

## 🛠️ Stack

- HTML / CSS / JavaScript (sin frameworks, para máxima simplicidad y portabilidad).
- Pensado para conectarse a la API de Claude (Anthropic) en producción — esta demo pública corre en **modo demostración** con un guion fijo, para que cualquiera pueda probarla sin necesidad de una API key.
- Backend de referencia en Node.js/Express incluido en el diseño original, listo para conectar la IA real.
